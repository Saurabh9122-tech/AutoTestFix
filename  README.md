# AutoTestFix

AutoTestFix is an execution-guided autonomous AI agent for software testing, debugging, and automated program repair.

## Project Goal

The system aims to analyze a software repository, execute tests, identify failures, localize suspicious code, generate candidate repairs, execute those repairs in an isolated environment, and verify them using automated testing and regression testing.

## Core Workflow

Repository
→ Test Execution
→ Failure Analysis
→ Fault Localization
→ Root Cause Analysis
→ Patch Generation
→ Sandbox Execution
→ Regression Testing
→ Verification
